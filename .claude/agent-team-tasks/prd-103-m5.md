*The argument #3 gave was non-discriminating and should not have decided anything.* It was the auditor's second-order note — if the shebang or base image ever changes, `[ -O x ] && chmod` on a shell where `-O` is undefined **skips the chmod silently**, because POSIX exempts the left of an AND-list from errexit so `set -eu` does not fire. That hazard is real and worth a comment at the three sites, **but it applies to BOTH candidate forms equally**: a `disable=SC3067` comment and a `shell=busybox` directive both go on suppressing after a shebang change.
