### Fixed

- **A push refused only with a bare `(failed)` remote rejection is retried instead of failing the run (#3929).**
  The worker's finalize branch push now treats git's reasonless `! [remote rejected] ... (failed)` line as transient and retries the same non-forced push with full publication proof on the existing ~31 s backoff, then falls to `publication_forge_unreachable: push`; every other rejection stays permanent, and a deterministic refusal that prints only `(failed)` is retried needlessly.
