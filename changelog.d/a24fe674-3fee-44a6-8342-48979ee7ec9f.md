### Added

- **Operators can bind Claude runs to an allowlisted Anthropic-Messages-compatible model endpoint instead of Anthropic's API (PRD #229 D10).**
  `ANTHROPIC_ENDPOINT_URL` plus `ANTHROPIC_ENDPOINT_API_KEY` point this instance's Claude path at a custom host, which must appear on `ANTHROPIC_ENDPOINT_ALLOWED_BASE_URLS` or the boot fails, since repo contents travel to whatever endpoint a run talks to. A bound run's claim carries no subscription token and `buildSdkEnv` drops `CLAUDE_CODE_OAUTH_TOKEN` in the same object that sets `ANTHROPIC_BASE_URL`, so the two never reach the SDK together; `ANTHROPIC_BASE_URL` also joins `PROTECTED_ENV_KEYS`. Codex runs are never bound, and an instance with no endpoint configured emits a byte-identical claim and env to today.
