### Security

- **The Claude CLI now reads its global config from a directory the agent cannot write (#4416).**
  Every Claude CLI start runs with `CLAUDE_CONFIG_DIR=<HOME>/.uzi-claude-config`, a worker-owned directory holding fixed config bytes and links to the run's transcripts, so an `env` block an agent writes to `HOME/.claude.json` or `HOME/.claude/` is not applied; unexpected entries at that path are renamed aside and rebuilt, and the start is refused when that cannot be done or the layout cannot be trusted (a read-only data volume, a home directory failing the ownership and parent-mode checks, a repeated or transient failure preparing the transcript directories, or a directory that keeps changing). With a single uid there is no protection, and a real OAuth subscription session was not tested against an unsigned stored remote-settings file.
