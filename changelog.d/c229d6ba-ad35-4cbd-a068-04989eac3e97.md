### Fixed

- **An owner token switch on a run with retained recovery work no longer fails it worker_residue_blocked (#3181).**
  The worker now proves the run's processes stopped before reporting the switch, else the run is held for its owner (credential_switch_settling, then credential_switch_unsettled; Resume or Cancel), and the next claim still runs its fail-closed predecessor proof. An API without the credential_switch_hold feature, a refused or unconfirmed hold report, or a retained flight at an awaiting gate keeps the previous non-terminal stop.
