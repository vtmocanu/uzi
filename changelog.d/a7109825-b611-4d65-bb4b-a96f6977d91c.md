### Changed

- **Settings has a Models tab with one save for every model choice (#3263).**
  The default harness, worker, planning, judge, summary, task-review and cross-check models and efforts moved from Run defaults to one Settings → Models grid that saves in one transaction; `PUT /api/me/model-settings` now accepts 19 fields (with `uza_`/`uzc_` tokens too), returns per-field `errors` on a 400 and `{settings, effective}` on success, and the writes are atomic while the response reads are separate queries, not a snapshot.
