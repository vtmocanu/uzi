### Added

- **Runs receive their repo's variables as environment variables (#4416).**
  Lead-agent runs on both harnesses get the enabled variables in every command at the lowest precedence, with secret values redacted from output (raw, JSON, HTML-safe, percent and base64 forms, and each qualifying line of a multi-line value) and every publish searched for them, failing closed; a claim whose secret forms pass the form cap fails before any work as `run_env_forms_over_budget`, and it needs a worker that reports `run_env_v1`, so a lead-agent run whose repo has an enabled variable is not claimed by an older worker.
