### Added

- **Custom Anthropic-compatible model providers (#4320).**
  Users can define a provider (a named endpoint with its own key and model map) at a base URL the operator allowed with `UZI_PROVIDER_ALLOWED_BASE_URLS`; this first step adds a Custom providers card in Settings and `uzi provider list|create|edit|test|retire` to manage them, plus a Test probe that checks the key and tool use against the gateway, and no run uses a provider yet. A gateway behind a private CA is trusted through `workers.extraCA`, which the chart now also mounts into the api pod (an inline `workers.extraCA.pem` change rolls the pod, and the api refuses to boot on an unparseable bundle).
