### Added

- **Scoped usage analytics API with filter options and Spend (#4684).**
  Owner routes `/api/analytics/{options,spend}` and admin routes `/api/admin/analytics/{options,spend}` return calendar-bucketed spend, ranked splits, cost per completed run and per merged PR, and per-run cost disclosure; API only, and an admin all-users `window=all` request over very large histories can exceed its 8 s budget and return 503.
