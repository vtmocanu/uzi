### Changed

- **A run whose retained recovery was refused only for data volume capacity is now held for the owner (#4046).**
  Such a window no longer spends a counted park or a retry timer; the run keeps its worker and source custody until the owner chooses Resume (one more window) or Cancel, so freeing headroom alone no longer auto-resumes it. Mixed or deadline-only windows keep today's counted, timed park, and an older API falls back to the unmarked report.
