### Added

- **Operators can opt in to age-based expiry of recorded history with `UZI_HISTORY_RETENTION` (#4695).**
  Off by default; a sweeper pass deletes ordinary PR history events and usage and capacity samples older than the set age (at least `24h`), never the PR heads or first-merge events, with the new btree indexes built at boot and the upgrade needing one migrating API process and possibly a longer startup probe.
