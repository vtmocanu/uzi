### Added

- **Planning uses the repo's agents when you request them (#3914).**
  With repo agents requested for a run and a roster at its recorded revision, the plan turn delegates to the repo's agents before you review the plan: Claude planning agents lose their write tools, Codex refuses every planning file write, the shell stays available, and the lead treats their output as unverified. A recorded choice of your templates keeps planning on them, and the run page and `uzi run get` show which agents planned the run.
