### Added

- **Admins can read another user's held publications and filter the debug run listing by status (#4614).**
  `uzi run held <id>` and `uzi admin runs --all [--user <uuid|email>] [--since <rfc3339>] [--status s[,s]]` join the flag-gated, audited admin run debug reads (`UZI_ADMIN_RUN_DEBUG`, `uza_` token); held expiry stays owner-only.
