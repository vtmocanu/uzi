### Fixed

- **Worker images ship a pinned pnpm, so pnpm repositories get their dependencies installed (#3906).**
  Both worker images bake an integrity-checked pnpm 10.34.9 without Corepack; the pre-approval install also pins pnpm's virtual store inside the clone and its content store to a private per-run directory, so a repository's own pnpm location settings cannot make the install write outside the clone, and every image build runs an offline proof that the tested repository lifecycle scripts, pnpmfile hooks, config-dependency plugin hooks and declared pnpm versions do not run.
