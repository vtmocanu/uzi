### Added

- **Automatic CI fixes can be turned off for one run's branch (#4617).**
  `uzi run ci-autofix <run-id> --enabled=false`, the run page checkbox or `PUT /api/runs/{id}/ci-autofix` sets a per-run override (or `--clear` to follow your account default); every CI fix on that branch copies it, the automatic path re-checks it before starting a fix, and the admin switch still wins.
