### Added

- **Admin all-users all-time Spend is served from a scheduled snapshot (#4771).**
  `UZI_ANALYTICS_SNAPSHOT_INTERVAL` (default `4h`, `0` off, at least `1h` otherwise) sets how often the API rebuilds the stored 25 `split` x `breakdown` variants; requests read the stored document with a `snapshot` block and answer 503 until the first build, while filtered or non-UTC requests and the other sections keep a 400.
