### Changed

- **Analytics repo options list only repos with runs in the scope (#4780).**
  `/api/analytics/options` and `/api/admin/analytics/options` now list the repos that have at least one run in the scope (any time, any kind) instead of every repo on the connections, so an admin all-users list is no longer filled with repos nobody ran on. The `repo` filter of every analytics section still accepts any repo the scope can see.
