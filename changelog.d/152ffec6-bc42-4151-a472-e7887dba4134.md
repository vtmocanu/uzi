### Fixed

- **A bound custom endpoint now names the model it serves, and its runs stop calling Anthropic's classifier (PRD #229 D10).**
  `ANTHROPIC_ENDPOINT_MODEL` is required alongside the endpoint URL, and the model slug rides the claim into `ANTHROPIC_MODEL`; without it a bound run sent Anthropic's default model name to a gateway that does not serve it, which failed inside the provider with no uzi-side diagnostic. `CLAUDE_CODE_AUTO_MODE_SERVER` is now pinned in `PROTECTED_ENV_KEYS` and set to `0` for a bound run, so the auto-mode classifier no longer egresses to Anthropic on the one path the endpoint exists to replace.
