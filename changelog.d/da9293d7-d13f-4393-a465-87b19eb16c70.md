### Added

- **Hosted workers can trust an extra CA bundle.**
  The chart's `workers.extraCA` (inline PEM or an existing ConfigMap) is appended after the api's CA in each worker's Secret, so the worker and, without `workers.uidSplit`, the Claude Code CLI can reach a private-CA LLM gateway or self-hosted forge API over HTTPS. Workers also trust it for their own connection to the api. Under `workers.uidSplit` the CLI does not get it, and it does not change git's or the toolchain's trust, so `git clone` from a private-CA forge still fails.
