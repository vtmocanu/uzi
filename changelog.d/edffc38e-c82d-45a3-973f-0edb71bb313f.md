### Fixed

- **A follow-up run on the branch of a just-completed run no longer fails on the completed run's retained clone (#3404).**
  The successor now retires the completed owner's certified completion source itself (same proof checks as the background retirement) before seeding, so a `ci_fix` or repeated `mr_rework` run on an agent branch can proceed once that retirement's proof holds, instead of failing with a clone-path or retained-clone refusal.
