### Added

- **A run that cannot publish because the forge is unreachable now parks and resumes publication-only, with no model work (#1324).**
  A sustained transient failure at base refresh, push or merge request create parks the run with `recovery_wait_phase=publication` and keeps its source, retrying until `RUN_PROVIDER_PARK_MAX_DURATION` and then holding for an owner Resume that queues one publication-only episode; `RUN_PUBLICATION_RESUME_ENABLED` stops new enrollment only, and before an API rollback enrolled queued runs and timed waits must be converted to NULL holds.
