### Added

- **Admins can keep one idle worker warm and sleep the rest of an owner's interchangeable workers sooner (#4395).**
  The new `worker_hibernation_surplus` setting is off by default and only applies while automatic hibernation is on; surplus workers sleep after `worker_hibernation_surplus_idle_after` (default 2h), and a re-woken Docker worker starts with a pruned build cache.
