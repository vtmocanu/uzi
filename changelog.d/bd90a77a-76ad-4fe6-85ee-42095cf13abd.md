### Fixed

- **The Claude re-plan gate checkpoint step now has a 60-second deadline (#3980).**
  The step fails closed like a failed checkpoint (transient recovery error, source clone kept, candidate reservation untouched) and finishes in about 76 seconds provided its untimed operations (process probes and kills, a kernel-blocked procfs read, a child that never closes) return, superseding the 0.87.0 note that a re-plan gate checkpoint still had no fixed limit.
