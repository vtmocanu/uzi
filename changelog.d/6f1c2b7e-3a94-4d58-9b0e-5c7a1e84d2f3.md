### Added

- **Reasoning effort can be set to Runtime default for Claude and Codex (#3247).**
  Settings → Run defaults → Reasoning effort sends no effort level, so the runtime chooses and the level used is not reported; unset still means medium, and cross-check checkers are unaffected.
- **Codex warns when its catalog does not list the chosen reasoning effort (#3247).**
  The worker reads the runtime's `model/list` catalog read-only before the first turn and shows one advisory run-feed warning; the level is still sent unchanged and never rewritten or retried, and an unreadable or timed-out catalog warns nothing.
