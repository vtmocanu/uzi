### Added

- **A Codex `docker login` now lasts for the rest of the run (#4416).**
  On Claude a login already did, and the worker now pins `DOCKER_CONFIG` to the run home's `.docker` directory on both harnesses; both apply only when Docker is wired on the worker. A resumed run may need to log in again, and other runs of the same user on the worker can read the directory except where Landlock is applied (always in the Codex `required` sandbox mode, and in `best-effort` on a kernel with Landlock). See docs/run-env-vars.md.
