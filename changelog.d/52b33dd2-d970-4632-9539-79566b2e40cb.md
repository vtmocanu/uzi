### Added

- **Docker registry logins now last for the whole run on both harnesses (#4416).**
  Each run keeps its Docker client configuration in a `.docker` directory in its run home, so a `docker login` is used by later pulls and builds; a resumed run may need to log in again, and other runs of the same user on the worker can read the directory unless the Codex command sandbox is `required`. See docs/run-env-vars.md.
