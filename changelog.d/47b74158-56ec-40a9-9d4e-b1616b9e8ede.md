### Changed

- **The run judge has a model setting per harness, and admins can reset the instance judge model to the built-in default (#3245).**
  The Claude lane (`judge_model`) and the new Codex lane (`codex_judge_model`, curated ids only, built-in `gpt-6.1-sol`) each resolve user, then instance, then built-in for the judge run's harness; a value invalid for that harness is skipped with a note. A curated Codex id stored in `judge_model` is copied into the Codex lane, and any Codex id there is skipped by Claude judges (reset it to Default to clear it); an empty or whitespace-only instance judge model resets to the built-in, and `uzi settings get` prints a Model settings table.
