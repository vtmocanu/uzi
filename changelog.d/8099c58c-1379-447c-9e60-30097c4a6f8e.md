### Added

- **Admins can read other users' run debug data from the CLI behind an opt-in flag (#4198).**
  With `UZI_ADMIN_RUN_DEBUG` (chart `api.adminRunDebug.enabled`, off by default) a live admin's `admin_ro` `uza_` token reads a foreign run's inputs, archive metadata and fetches, `run recovery --user` and `<run-id>` holds, and `admin runs --all` (max 500, `truncated` flag); every such read is audited, writes, downloads and `run export` stay owner-only, and `run recovery <run-id> --json` may now end with an `unattached` captures element.
