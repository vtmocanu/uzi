### Added

- **`uzi run set-token` now switches a live Claude run's token without restarting its claim (#4201).**
  On a worker and api that both support in-place switching, the run keeps its worker, claim and working directory and the agent restarts on the new token with the same session; if the switch cannot be confirmed the run pauses for you and Resume re-reads the token from the run's current choice, and older workers keep the release-and-reclaim path.
