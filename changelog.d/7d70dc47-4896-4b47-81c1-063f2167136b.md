### Added

- **`/server setup` connects a forge and enables repos from a script (#3760).**
  Run it inside the deployment with `docker compose exec` or `kubectl exec -i`: it reuses the web UI checks (least-privilege token, protected default branch, board columns), reads the forge token from a file or stdin, writes one JSON report and exits 0, 1 or 2. Worker creation follows in a later release.
