Canonical schedule preset parity cases live in `canonical.json`, a JSON array of `{cron, preset, hour, minute, ok}`. Go's `TestSchedulePresetsCanonical` consumes every row; the web implementation should consume the same file for renderer/inverse parity. For `every_n_minutes` and `every_n_hours`, `hour` carries interval N and `minute` is zero. For clock presets they carry the clock time. Custom rows have `ok: false` and zero parameters. Minute intervals are limited to the listed divisors of 60; `*/40` is custom.
