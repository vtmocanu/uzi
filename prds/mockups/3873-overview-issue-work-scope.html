Issue work: a You | All users scope toggle for admins

The same segmented toggle as the usage card (#3881), pinned to the far right of the Issue work header, like the usage card's toggles, so it never shifts when the note's length changes (dashed outline marks what is new). Admins only; non-admins see today's card with no toggle. Click the toggle and the stations; press a pressed station again to clear the filter. Example data.

Theme

0 · Consistency: the usage card header (#3881) with the same label

The usage card's scope option is renamed from "Factory · all users" to "All users", and both cards remember their scope per browser (default You).

Usage

1 · Desktop, default scope: You

Counts, badges, captions and bays use only your runs. The Runs widget below would filter to your runs when a station is pressed.

2 · Desktop, All users (today's behaviour)

Other users' runs join the stations (dashed badges, owner on hover). Gate and question captions split "on you / on others". The PR station stays yours only and says so.

3 · Admin run list unavailable

The All users option is disabled and the card falls back to You with a note, as the Runs widget already does.

4 · Phone, 400 px

The toggle stays top-right beside the title; the note and Show all wrap to the row below; the line stacks vertically.

Decisions

  • Decided: default scope You; the choice is remembered per browser (localStorage, guarded so a blocked store falls back to You).
  • Decided: toggle pinned to the far right of the header.
  • Decided: no "Show all" button; press the pressed station or bay again to clear the filter.
  • Label: You | All users on both cards.
  • Per-card toggles, not one page-level scope.
  • Under You, a pressed stage filters the Runs widget to the viewer's runs only; unfiltered, the Runs widget is unchanged.
  • The PR station stays the viewer's own PRs in both scopes.
