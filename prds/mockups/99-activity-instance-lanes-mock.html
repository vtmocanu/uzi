Three decisions

Fewer duplicates

Identity = invocation, not order

A lane is keyed by the subagent's parent_tool_use_id (lead = the parentless lane). Non-adjacent turns coalesce, so the ping-pong stops multiplying labelled bars.

Status at a glance

A dot on every lane

Collapsed lanes still show life, via the same crewStateFor() ladder the pane already computes. The word beside the dot is the label — so no standing legend, just a title tooltip:

  • working
  • stalled
  • waiting
  • idle
  • done

Two coders

Named by task, never "#2"

Each parallel coder is its own lane, titled with the spawning Task's description (web gate UX vs API wiring). You see what each is doing, not a serial number.

Mockup only — no code changed. The one thing not free today: parent_tool_use_id + the Task description exist in the Agent SDK but are dropped at sdk-messages.ts:28 and absent from the run_messages wire. Making two coders truly distinct needs that field threaded through agent → api (migration) → web. Everything else is a web/-only refactor of ActivityFeed.tsx.
