2. The Agents chip: three options

The idea I drew first ("3 agents active of 16" from each run's latest step) is dropped: the run list shows only the agent behind each run's latest step, so it misses subagents working in parallel and reads low; "of 16" (your templates) does not match factory-wide activity; and the admin run list stops at 500. The honest choices are below.

D. Your idea: how many agents are configured, and where each comes from new recommendation

The chip counts the agents configured in uzi (the shared builtin and global ones, plus your own private ones). The popover splits them by where the definition comes from, so an overridden agent stands out from the shipped defaults. Every template already carries this (its origin), and the Overview already loads the list: no new API, always accurate.

D for a synced install (your setup): count by source, plus the sync status revised
