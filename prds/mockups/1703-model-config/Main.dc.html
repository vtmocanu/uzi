Run judge 5

With the run judge on, each of your finished runs is reviewed by an LLM on your own Anthropic tokens. It reads the run trace and produces a verdict plus recommendations. Results appear on the Judge page and on the run's page, plus a Slack DM when your Slack account is linked. It only recommends and never changes code. Off by default.

Harness and worker models 3

Choose how new runs start, then keep a model default for each harness. The worker model is what your runs use (the lead orchestrator and the subagents that inherit it) and overrides the lead template for your own runs only. Changing the harness doesn't overwrite either model choice.
