Run judge 11

When on, every finished run of an opted-in user is reviewed by an LLM on that user's own Anthropic tokens. This switch arms the feature instance-wide; each user still opts in under their own Settings. Off by default.

The Claude model the judge runs on. The default is opus, the strongest model, since judge recommendations feed self-improvement. Admins and users can pin haiku or sonnet to spend less.
