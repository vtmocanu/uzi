Sidebar usage: one list of accounts

Today the Claude block is named by account (TEAM) and the Codex block by provider (CODEX), and a single account is never named at all. The proposal: every account is named by its own alias, with the provider icon in front, in one list, Claude first. No provider words; hover an icon for the provider name. One "+N more" line covers both providers.

Claude account Codex account Claude: the Claude mark from simple-icons (same source as the GitLab icon uzi already ships). Codex: the OpenAI mark from Bootstrap Icons (MIT), the usual icon other agent dashboards show for Codex.
