Good for a glanceable number, but it sits lower on the page and cannot list who without its own popover. A answers the question where the eye lands first.

What the numbers mean

  • Active now: owns at least one run in the admin active-runs list the preview already loads (running, queued, parked, or waiting on them; chat, judge and cross-check runs are not listed), so it needs no new API. That list is capped at 500 rows: at the cap the chip says "at least N", and when the fetch fails it says "Active now unavailable".
  • Of 9: all enabled accounts, from the admin user list.
  • Signed in within 24h, no listed active run: from each account's last sign-in time, which the server already stores. uzi does not track who has a browser tab open, so "online" is not claimed.
  • This week: people with runs that recorded usage in the last 7 days, from the admin usage data the page already loads.
  • "for N people" in the status sentence counts only the owners of executing runs.
  • Non-admins see no chip: they only see their own work. The status sentence gains "for N people" for admins only.
