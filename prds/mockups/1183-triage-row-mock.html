  1. 10Mine / All users, admins only, remembered per browser. The switch Notifications already has. Default is Mine; the last choice is saved through the existing per-browser preference wrapper (web/src/lib/prefs.ts, the one theme and board order use), so an admin who switches to All users lands there next time, in that browser only, and a non-admin never sees the switch. Today the backlog is owner-scoped and never consults IsAdmin; the run page is owner-or-admin, so an admin already sees every recommendation, one run at a time, with the owner's name on it. This adds the roll-up and takes the name off.
  2. 11Attribution hidden, honestly. No owner, no run title, no run link, and no filed-issue link either (a forge URL carries the owner's namespace); occurrences are "a run, judged 2h ago" with a bare state chip; "6 users" says how widespread it is. Rationale text can still name a repo or a file, so the docs say "aggregated across users", never "anonymous", and users who opt into the judge are told an admin sees the aggregate.
  3. 12Instance-level categories by default. Improve uzi, Install a worker tool and the three template categories are things only an admin can act on. Enable a tool and Cost efficiency are one user's config and spend: off by default, one click to widen.
  4. 13File and Mark done, no Dismiss. Filing across users already exists (PRD #68). Mark done fans out to every user's open occurrence with a new provenance value admin, so their row reads "Done by an admin via #N" and keeps its Undo, next to the existing "Done via issue close". Dismissing someone else's recommendation is their judgment, so the button is not there.
