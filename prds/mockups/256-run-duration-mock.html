What to decide (review mock — nothing built yet)

What each duration means
queued = since created · running = since started · waiting = time parked in the current state (awaiting approval / your answer / a usage limit) · ran = total started→finished (static).
Keep the timestamp?
Shown here alongside the existing 08/08/2026, 17:39:36. Option: replace it — for an active run "how long" is more useful than a wall-clock "last updated". Your call.
Live vs static
Active rows tick (the list already reloads; a light client timer keeps seconds honest between reloads). Past rows show a fixed total.
Format
Rolls over to hours: 44s → 8m → 1h 30m → 2d 4h. Never bare 90m.
Scope
Web-only. All needed timestamps are already on the row DTO (RunListItemDTO → RunDTO). Same treatment fits the admin "Active runs · all users" list on this page.
